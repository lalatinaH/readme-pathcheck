# Roadmap

These are candidates, not promised features or delivery dates. Real failure reports should decide the order.

## Useful next contributions

- Raw HTML image/link extraction and custom anchor IDs with fixtures.
- Exact link line/column locations inside multiline paragraphs.
- Optional `.gitignore` support with clear scan-versus-target semantics.
- More fixtures from real documentation, especially non-Latin filenames and heading extensions.
- Stable npm releases after a publishing account and release process are established.

## Evidence to collect

Track actual bug reports, reviewed pull requests, releases, and downstream repositories that choose to run the checker. Ask permission before listing another project's name as a user. Record known false positives and fix them with regression tests.

The project should earn continued maintenance through usefulness. A new repository, a test count, or an AI-generated codebase does not establish adoption or qualify it for a sponsorship program.
