# Changelog

## 0.1.0

Initial release.

- Offline checks for local Markdown links and images.
- Exact-case and Unicode-spelling diagnostics with suggested destinations.
- GitHub-style heading checks with duplicate and non-Latin heading support.
- JSON output, GitHub Actions annotations, exclusions, and documented exit codes.
- Read-only operation with symlink boundaries and no runtime network access.
- English and Traditional Chinese documentation.
- Tests and CI configuration for Linux, Windows, and macOS.

Raw HTML links, custom HTML anchors, MDX, and external URL checks are not included.
